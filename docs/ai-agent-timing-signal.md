# Why AI browser agents have their own timing signal

This page moved to the invisible_playwright_mcp wiki, where the agent-experience content now
lives:

**[The timing signal AI agents give off](https://github.com/feder-cr/invisible_playwright_mcp/wiki/ai-agent-timing-signal)**

The short version it still owes you here: a think-act loop pauses for model
latency, and that pause repeats with a regularity no human produces. The
pointer arc between actions is the engine's job, and this engine humanises it;
the step-to-step rhythm is produced by the agent loop, which no fingerprint
work reaches.

[mouse-dynamics behavioural biometrics](mouse-dynamics-behavioural-biometrics.md),
[keystroke timing detection](keystroke-timing-detection-playwright.md), and
